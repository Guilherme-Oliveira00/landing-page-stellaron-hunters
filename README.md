# 🌌 Stellaron Hunters | Landing Page

Uma landing page interativa inspirada na misteriosa facção "Caçadores de Stellaron" do jogo Honkai: Star Rail. 

Este projeto foi construído do zero com o objetivo de treinar e consolidar os fundamentos clássicos do Front-end, com foco principal em **Manipulação do DOM** e estilização utilizando **CSS puro (Vanilla)**, sem o uso de frameworks.

## 🎮 Funcionalidades

- **Seleção Dinâmica de Personagens:** Alternância instantânea de telas e descrições via JavaScript ao clicar nos ícones laterais.
- **Identidade Visual Única (Neon):** Botões com efeito *glassmorphism* (fundo de vidro) e contornos em neon que mudam para a cor característica de cada personagem ao serem selecionados.
- **Design Responsivo:** Layout que se adapta perfeitamente entre monitores Desktop e telas de Celular (Mobile), trocando inclusive as imagens de fundo para garantir o melhor enquadramento dos personagens.
- **Transições Suaves:** Animações e efeitos de *hover* e *fade* construídos puramente com CSS Transitions.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura e semântica com uso da tag `<picture>` para responsividade de imagens).
- **CSS3** (CSS puro, Flexbox, variáveis, Media Queries, sombras e filtros avançados).
- **JavaScript** (Vanilla JS, Event Listeners, `querySelectorAll`, `classList`, Arrow Functions e Lógica de Índices).

## 🚀 O que eu consolidei neste projeto?

* **Foco 100% nos Fundamentos (Vanilla):** Optei por **não utilizar** frameworks CSS ou bibliotecas (como Tailwind ou React) neste momento. A arquitetura foi dividida manualmente de forma limpa (reset, style, responsive) para treinar o posicionamento e a estilização raiz.
* **Lógica Avançada de DOM:** Criei rotinas no JavaScript para iterar listas de elementos usando `forEach`, capturar o `index` (slot) do elemento clicado e sincronizar com a exibição da tela correspondente.
* **Debug e Resolução de Problemas:** Treinamento prático na identificação de bugs de referência clássicos do JavaScript (como erros de leitura de propriedades `null` no DOM).
